Frequently asked questions

How do I paste a table from Excel or Google Sheets?

Copy the cells, click the grid cell where the data should start, and paste. The table grows to fit. You can also use Import to replace the whole table.

Can I edit an existing Markdown table?

Yes. Click Import, paste the Markdown table and choose “Fill table”. The cells and column alignment are loaded into the grid.

Where do Markdown tables work?

Anywhere that supports GitHub Flavored Markdown, including GitHub, GitLab, Notion, Obsidian, Reddit and most documentation tools.
