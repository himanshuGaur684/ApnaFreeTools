Frequently asked questions

Where is my writing saved?

In your browser’s local storage on this device. It is never sent to a server. Clearing your browser data, or using a private window, removes it — download a copy of anything you want to keep.

Which Markdown syntax is supported?

GitHub Flavored Markdown: headings, bold, italic, strikethrough, lists, task lists, tables, links, images, quotes, inline code and fenced code blocks.

Are there keyboard shortcuts?

Ctrl/Cmd + B for bold, Ctrl/Cmd + I for italic, Ctrl/Cmd + K for a link, and Tab to indent.
