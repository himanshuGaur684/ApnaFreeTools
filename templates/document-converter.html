Frequently asked questions

Is this converter really free?

Yes. There is no sign-up, no watermark and no limit on the number of conversions.

Are my files uploaded anywhere?

No. Every conversion runs entirely in your browser, so your documents never leave your device.

Which Markdown features are supported?

Headings, paragraphs, bold, italic, strikethrough, inline code, fenced code blocks, ordered, unordered and task lists (including nested lists), tables, block quotes, links, horizontal rules and images.

Which conversions are available?

Markdown to DOCX, PDF or HTML; DOCX, PDF or HTML to Markdown; and DOCX to PDF or HTML.

Does Word to PDF keep the exact layout?

It keeps the content and structure — headings, text formatting, lists, tables, links and images — in a clean, consistent style. Original fonts, colours, page margins, headers and footers are not reproduced.

How accurate is PDF to Markdown?

A PDF stores positioned text rather than structure, so headings, lists, bold text, code and simple tables are detected from the layout. Text-based PDFs work well; complex layouts such as multiple columns may need a little clean-up. Scanned PDFs (pictures of pages) contain no text to extract.

Can I convert older .doc files?

Only the modern .docx format is supported. Open a .doc file in Word or Google Docs and save it as .docx first.

What happens to images?

Markdown → DOCX and Markdown → PDF embed PNG and JPEG images that your browser is able to load. DOCX → Markdown drops images by default; tick “Keep images” to embed them in the Markdown as base64 data. DOCX → PDF and DOCX → HTML keep the document’s images. Images inside a PDF are not extracted.
