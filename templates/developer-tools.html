    Frequently asked questions

    Is it safe to paste tokens, passwords or private data here?

    Everything on this page runs in your browser. Nothing you paste or generate is uploaded, logged or stored. For highly sensitive production secrets, your organisation’s own approved tools are still the safest choice.

    How does JSON to CSV handle nested data?

    Each object in the list becomes a row. Nested objects are flattened into columns named like address.city, and arrays are kept as JSON text in a single cell. Going from CSV to JSON, values with leading zeros such as PIN codes and phone numbers stay as text.

    Which regular expression syntax does the tester use?

    JavaScript’s, the same as browsers and Node.js. Most patterns also work in other languages, but features such as lookbehind and named groups differ slightly between engines.

    How does the timestamp converter know seconds from milliseconds?

    By the size of the number: 10 digits is read as seconds, 13 as milliseconds, 16 as microseconds and 19 as nanoseconds. The page shows which one it used.

    Which cron format does the explainer support?

    The standard five-part format: minute, hour, day of month, month and day of week. It does not cover the six- or seven-part formats with seconds or years used by Quartz and some cloud schedulers.

    What do the contrast results mean?

    WCAG asks for a contrast ratio of at least 4.5 : 1 for normal text and 3 : 1 for large text to meet level AA, and 7 : 1 and 4.5 : 1 for the stricter level AAA.

    Is the sample data real?

    No. Names are random combinations of common Indian first names and surnames, emails use the reserved example.com domain, and phone numbers and PIN codes are random digits in a realistic format.

    Does the JWT decoder verify the signature?

    No. It only decodes the header and payload so you can read them. Verifying a signature needs the secret or public key and should be done by your server.

    What is the difference between UUID v4 and v7?

    Version 4 is fully random. Version 7 starts with the current time, so the IDs sort in the order they were created, which suits database keys.

    Which hash should I use?

    Use SHA-256 for checksums and general use. MD5 and SHA-1 are only suitable for checking file integrity against a published value. None of these is right for storing passwords — use a password-hashing function such as bcrypt or Argon2 for that.

    How does the UPI QR code work?

    It encodes a standard UPI payment link with your UPI ID and, if you add them, a name, amount and note. Any UPI app can scan it. Check the UPI ID carefully and test the code with a small payment before using it.

    Do the QR codes expire?

    No. The information is stored in the code itself, with no tracking link or account behind it, so it works for as long as the link or details stay valid.
